# ◈ استشراف المستقبل (Istishraf)

**محرك الذكاء الجمعي التفاعلي لاستشراف السيناريوهات المستقبلية باللغة العربية**

تطبيق ويب وتطبيق أندرويد أصيل (`com.istishraf.app`) يحوّل الأخبار والوثائق والسياسات إلى عوالم رقمية موازية يتفاعل فيها وكلاء ذكاء اصطناعي مستقلون لاستنباط المسارات المستقبلية وتوليد تقارير تحليلية معمّقة.

## ✨ أبرز المزايا
- **واجهة عربية كاملة (RTL)** مع دعم الإنجليزية والصينية وتثبيت **PWA**.
- **نظام حسابات متعدد المستخدمين للجمهور العام:** عزل كامل لمشاريع ومحاكاة كل مستخدم مع حصص يومية آمنة، وصلاحية حصرية لمدير النظام (أول حساب مسجّل) لإدارة مفاتيح الذكاء الاصطناعي.
- **نشر مجاني سحابي كامل:** جاهز للعمل مباشرة على **Hugging Face Spaces (Docker - 16GB RAM مجاناً)** و**Vercel** (للواجهة) و**Render / Railway**.
- **تطبيق أندرويد (`APK` + `AAB`):** جاهز للبناء التلقائي عبر GitHub Actions (`Capacitor Android`).

راجع ملف **[دليل_إطلاق_تطبيق_استشراف.md](./دليل_إطلاق_تطبيق_استشراف.md)** لخطوات التشغيل التفصيلية.
